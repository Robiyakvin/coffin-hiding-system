# coffin-hiding-system

A reusable Roblox coffin hiding system featuring interactive entry and exit, character concealment, automatic restoration, and multiplayer support. Perfect for horror, survival, and stealth games.

⚰️ COFFIN HIDING SYSTEM

A reusable hiding system for Roblox experiences.

Make hiding mechanics easy to implement with Coffin Hiding System!

✨ Features

- Interactive Coffin: Players can enter and exit using a ProximityPrompt.
- Character Concealment: Hides the player's character while inside.
- Automatic Restoration: Restores character visibility and collision when exiting.
- Respawn Handling: Designed to handle player death and respawning.
- Multiplayer Support: Each coffin can only be occupied by one player at a time.
- Reusable System: Designed for integration into different Roblox experiences.

🛠️ Use Cases

- Horror games
- Survival games
- Stealth mechanics
- Hide-and-seek experiences
- Roleplay games
